# Bot detection challenge

Проект по обнаружению ботов по поведению cookie за одни сутки.

## Порядок запуска

1. Открыть `eda.ipynb` для разбора исходных данных.
2. Запустить `fe.ipynb`. Ноутбук удаляет полные дубли событий, применяет окно `[window_start_ts, window_end_ts)` и сохраняет признаки в `features/`.
3. Запустить `train.ipynb`. Он использует временную проверку, подбирает LightGBM и CatBoost, сравнивает схемы и сохраняет `submission.csv` и графики в `results/`.

Случайное разбиение не используется: дни 17–19 апреля оставлены как внешняя проверка, test относится к следующей неделе.

## Результат

Текущая матрица содержит 110 признаков. В `submission.csv` 4909 строк, порядок cookie совпадает с `data/test.csv`, score находится в диапазоне `[0, 1]`.

## Структура

- `eda.ipynb` — исследование данных без сохранения результатов в проектные таблицы.
- `fe.ipynb` — построение признаков для train и test.
- `train.ipynb` — валидация, подбор моделей и submission.
- `metric.py` — метрика Precision при Recall не ниже 70%.
- `features/` — parquet-матрицы и список признаков.
- `results/` — таблицы сравнений, trials и графики.
